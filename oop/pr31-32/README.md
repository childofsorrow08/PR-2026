1) У чому різниця між раннім та пізнім зв’язуванням?

- При ранньому зв’язуванні виклик визначається під час компіляції, при пізньому конкретна реалізація вибирається під час виконання за типом об’єкта.

2) Яку роль відіграє ключове слово virtual у C#?

- virtual дозволяє перевизначити метод у класі-нащадку через override.

3) У яких випадках краще використовувати пізнє зв’язування?

- Коли однаковий виклик має виконувати різну роботу залежно від конкретного об’єкта, наприклад розраховувати різні способи доставки.

4) Як реалізується пізнє зв’язування через інтерфейси?

- Змінна має тип інтерфейсу, а викликається реалізація методу того об’єкта, який у ній збережений.
