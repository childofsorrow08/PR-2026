1) Які способи створення файла та запису в нього тексту ви знаєте?

- Через StreamWriter, File.WriteAllText або File.WriteAllLines. У цій роботі використовується StreamWriter.

2) Які способи відкрити файл та прочитати з нього весь текст ви знаєте?

- Через StreamReader та ReadToEnd, або через File.ReadAllText і File.ReadAllLines.

3) Що станеться, якщо відкрити файл на читання і не закрити його вчасно?

- Файл залишиться відкритим, займатиме ресурси й може заважати іншим операціям із ним.

4) Для чого потрібен метод Flush?

- Щоб передати дані з буфера в нижчий потік, не чекаючи закриття StreamWriter.

5) Що таке потік і для чого призначені класи StreamWriter та StreamReader?

- Потік це послідовність даних. StreamWriter записує текст у потік, а StreamReader читає його з потоку.

6) Яку роль виконує оператор using під час роботи з потоками?

- using викликає Dispose і закриває потік при виході з блоку, навіть якщо виникла помилка.

7) Як відкрити StreamWriter для дописування в кінець файла без втрати його вмісту?

- Передати true другим аргументом: `new StreamWriter(path, true)`.

8) За якої умови можна змінити один рядок файла, не переписуючи весь файл?

- Коли відомий байтовий зсув рядка, а новий текст займає рівно стільки ж байтів, як старий.
