1) Що таке узагальнений метод і чим він відрізняється від узагальненого класу?

- Узагальнений метод працює з параметром типу в межах одного методу, в той час як узагальнений клас задає параметр типу для всього класу.

2) Який синтаксис використовується для оголошення параметра типу узагальненого методу?

- Параметр типу пишеться в кутових дужках після назви методу, наприклад `Min<T>(T[] array)`.

3) Як компілятор визначає тип-аргумент під час виклику узагальненого методу, якщо він не вказаний явно?

- За типами переданих аргументів. Якщо передати int[], компілятор визначить T як int.

4) Для чого потрібні обмеження параметра типу?

- Щоб дозволити лише потрібні типи й мати доступ до їхніх методів та властивостей.

5) Як синтаксично задається обмеження параметра типу в C#?

- Через where після параметрів методу, наприклад `where T : IComparable<T>`.

6) Чому метод IndexOf для масиву можна реалізувати без обмежень на параметр типу?

- Для пошуку достатньо перевірки рівності через `EqualityComparer<T>.Default`, яка доступна для будь-якого T.

7) Чому методи Min і Max неможливо коректно реалізувати без обмеження параметра типу?

- Для пошуку мінімуму та максимуму потрібно знати, як порівнювати елементи. У цій реалізації це задає IComparable<T>; сам оператор < для довільного T недоступний.

8) Що станеться під час компіляції, якщо викликати метод з обмеженням where T : IComparable<T> для типу, який цей інтерфейс не реалізує?

- Компілятор видасть помилку, бо тип не відповідає обмеженню.

9) Які ще види обмежень, крім IComparable<T>, можна накладати на параметр типу?

- Можна вказати class, struct, notnull, unmanaged, базовий клас, інтерфейси та new().
