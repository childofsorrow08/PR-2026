1) Чому підключення скрипту наприкінці <body> (або з атрибутом defer) вважається безпечнішим за підключення в <head> без цього атрибута?

- Скрипт виконується після розбору HTML і вже бачить потрібні елементи сторінки. Скрипт у head без defer може запуститися до їх створення.

2) Чим відрізняється поведінка оператора + від оператора - при роботі з рядком, який містить число?

- + може склеювати рядки, а - перетворює їх на числа. Наприклад, `"2" + 3` дасть "23", а `"2" - 3` дасть -1.

3) Яке значення поверне 10 + true і чому?

- 11, тому що true при додаванні перетворюється на 1.

4) Чому Number("125 грн") повертає NaN, а Number("") — 0?

- Рядок "125 грн" не є повним записом числа, тому виходить NaN. Порожній рядок при перетворенні на число дає 0.

5) Чому вираз Boolean("false") повертає true?

- Тому що це непорожній рядок, а його текст не впливає на логічне перетворення.

6) Які значення в JavaScript вважаються хибними (falsy)?

- false, 0, -0, 0n, порожній рядок, null, undefined та NaN.

7) Чим відрізняється область видимості змінної, оголошеної через var, від змінної, оголошеної через let?

- var має область видимості функції, в той час як let має область видимості блоку.

8) Чому глобальні змінні вважаються небажаними, якщо доступ до них з інших частин коду не є дійсно потрібним?

- Їх можуть випадково змінити інші частини коду, також вони ускладнюють розуміння залежностей.

9) За яким критерієм варто обирати між let і const при оголошенні змінної?

- Якщо значення змінної потрібно переприсвоювати, використовуємо let, інакше const. Вміст об’єкта в const змінювати можна.

10) Як зміниться доступність змінної, якщо перенести її оголошення з тіла функції в глобальну область видимості?

- Вона стане доступною за межами функції, у відповідній глобальній області видимості.
