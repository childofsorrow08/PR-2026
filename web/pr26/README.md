1) Що таке fetch api і для чого він використовується?

- Це API для HTTP-запитів із JavaScript, наприклад щоб отримати або відправити дані на сервер.

2) Чим асинхронний виклик відрізняється від синхронного? Чому мережеві запити виконуються асинхронно?

- Синхронний виклик затримує подальше виконання, а асинхронний дозволяє продовжити роботу під час очікування. Так мережевий запит не блокує інтерфейс.

3) Що таке Promise? У яких станах він може перебувати?

- Promise представляє майбутній результат операції. Стани: pending, fulfilled та rejected.

4) Як опрацювати результат проміса за допомогою then() і catch()? Як це зробити за допомогою async/await?

- У then обробляємо результат, у catch помилку. З async/await результат очікуємо через await усередині try, а помилку обробляємо в catch.

5) Як за допомогою fetch() виконати запити GET, POST, PUT і DELETE? Які налаштування потрібні в кожному випадку?

- GET виконується за замовчуванням. Для інших задаємо method; для POST і PUT із JSON додаємо Content-Type та body через JSON.stringify. Для DELETE у цій роботі достатньо методу й адреси з id.

6) Чому логіку завантаження даних із сервера варто відокремлювати від логіки оновлення вмісту сторінки?

- Щоб код запитів можна було використовувати повторно й змінювати окремо від інтерфейсу.
