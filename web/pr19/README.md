1) Що таке JavaScript та для чого використовується ця мова програмування?
- Мова програмування для логіки веб сторінок

2) Які основні відмінності між JavaScript та Java?
- Java це об'єктно орієнтована мова програмування для створення застосунків на різні пристрої, з принципом "написано один раз -працює всюди" та працює всередині віртуальної машини, в той час як JavaScript це високорівнева динамічна та інтерпритована мова програмування яка використовується для логіки веб створінок

3) Яку роль відіграє JavaScript у клієнтській частині вебзастосунків?  Які типи даних підтримує JavaScript?
- Клієнтський JavaScript реагує на дії користувача й оновлює інтерфейс. Типи: undefined, null, boolean, number, bigint, string, symbol, object. Масив — різновид об'єкта.

4) Чим відрізняються способи оголошення змінних let, const та var?
- var має функціональну область видимості та допускає повторне оголошення, в той час як let та const мають блочну область. Також const не можна змінювати
