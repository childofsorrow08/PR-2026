1) В чому принципова різниця між віртуальною машиною та докер контейнером?

- Віртуальна машина запускає окрему гостьову ОС, а контейнер використовує ядро системи, на якій працює Docker. На Windows та macOS Linux-контейнери зазвичай працюють через віртуальну машину.

2) Що таке докер хост?

- Це система, на якій працює Docker Engine і запускаються контейнери.

3) Як видалити докер образ якщо він використовується в контейнері?

- Спочатку зупинити й видалити контейнер, який його використовує, а потім виконати `docker image rm назва`.

4) В чому різниця між docker container, docker image та docker volume?

- Image це шаблон із файлами та налаштуваннями, container це його запущений або зупинений екземпляр, volume це окреме сховище даних.

5) Яка команда створює докер образ з докерфайла?

- `docker build -t назва .`

6) Яка інструкція в докерфайлі запускає програму яка буде виконуватись в контейнері?

- CMD задає команду за замовчуванням, а ENTRYPOINT задає основну програму контейнера. RUN виконується під час складання образу.
