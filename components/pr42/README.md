1) Чому проєкт Windows Forms краще відкривати у Visual Studio, а не у Visual Studio Code?

- Visual Studio має вбудований дизайнер Windows Forms і засоби для роботи з формами, яких немає в стандартному VS Code.

2) Для чого проєкти рішення організовують у папки рішення? Чи існують ці папки на диску?

- Щоб логічно згрупувати проєкти. Папки рішення віртуальні й не обов’язково існують на диску.

3) Яким чином визначається, яка форма відкривається першою під час запуску застосунку Windows Forms?

- Формою, яку передали в Application.Run під час запуску програми.

4) Навіщо клієнтський проєкт посилається на проєкт PostService.Dtos і яку перевагу це дає порівняно з копіюванням класів DTO? У якому випадку такий підхід неможливий?

- Щоб використовувати спільні типи й не підтримувати їхні копії. Пряме посилання не підходить, якщо клієнт написаний іншою мовою або не має доступу до цієї збірки.

5) Що таке HttpClient і навіщо задавати значення його властивості BaseAddress?

- HttpClient надсилає HTTP-запити. BaseAddress задає спільну початкову адресу для відносних маршрутів.

6) Чому виклик серверного методу має бути асинхронним? Що сталося б із вікном, якби застосунок очікував відповіді синхронно?

- Щоб під час очікування відповіді вікно продовжувало реагувати на дії. Синхронне очікування в UI-потоці призведе до зависання інтерфейсу.

7) Для чого обробник події Load позначають модифікатором async і чому в обробниках подій використовують async void, а в інших асинхронних методах — Task?

- async дозволяє використовувати await. Обробник події має повертати void за своїм контрактом, а Task в інших методах дозволяє очікувати завершення та обробляти помилки.

8) Як отримати дані з вибраного рядка DataGridView і як за цими даними викликати DELETE /postings/{id}?

- Отримати об’єкт через DataBoundItem вибраного рядка, взяти його Id та викликати DeleteAsync з адресою postings/{id}.

9) Чому після видалення запису таблицю оновлюють даними із сервера, а не просто прибирають рядок на формі?

- Щоб таблиця показувала фактичний стан сервера й враховувала інші зміни.

10) Навіщо код оновлення таблиці виносять в окремий метод і яку користь це дає в цій роботі?

- Щоб повторно використовувати оновлення після завантаження, створення, редагування та видалення записів.
