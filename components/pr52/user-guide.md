# Інструкція користувача Notepad — варіант 1

Інструкція стосується базових функцій Блокнота у Windows. Назви пунктів меню можуть відрізнятися залежно від мови та версії Windows; наведені клавіатурні скорочення допомагають знайти потрібну дію. Для роботи з уже наявним важливим файлом спершу збережіть окрему копію.

## 1. Робота з документами

### 1.1. Створити документ
1. Відкрийте меню «Пуск», введіть «Блокнот» або «Notepad» та запустіть програму.
2. Оберіть «Файл → Створити» або натисніть Ctrl+N. У сучасній версії також можна створити вкладку Ctrl+T.
3. Уведіть текст у робочій області. Новий документ готовий до збереження.

### 1.2. Відкрити наявний файл
1. Оберіть «Файл → Відкрити» або натисніть Ctrl+O.
2. Знайдіть папку й виберіть потрібний текстовий файл.
3. Натисніть «Відкрити». Якщо символи відображаються неправильно, перевірте кодування у вікні відкриття, коли така опція доступна.

### 1.3. Зберегти зміни
1. Натисніть Ctrl+S або оберіть «Файл → Зберегти».
2. Для нового документа вкажіть папку, назву, наприклад notes.txt, і кодування UTF-8.
3. Натисніть «Зберегти». Якщо програма пропонує замінити наявний файл, перевірте, що вибрано правильний документ.

### 1.4. Зберегти копію під іншою назвою
1. Оберіть «Файл → Зберегти як» або натисніть Ctrl+Shift+S.
2. Вкажіть іншу назву або папку.
3. Підтвердьте збереження. Вихідний файл залишиться окремим, подальші зміни зберігатимуться в копії.

## 2. Редагування та пошук

### 2.1. Скопіювати, вирізати й вставити текст
1. Виділіть потрібний фрагмент мишею або клавішами Shift і стрілками; Ctrl+A виділяє весь текст.
2. Натисніть Ctrl+C для копіювання або Ctrl+X для переміщення.
3. Установіть курсор у місце призначення й натисніть Ctrl+V.

### 2.2. Знайти фрагмент
1. Натисніть Ctrl+F.
2. Введіть шукане слово чи фразу та, за потреби, налаштуйте врахування регістру.
3. Натисніть Enter або кнопку пошуку наступного збігу. Збіг буде виділено; повторіть пошук для наступного входження.

### 2.3. Замінити текст
1. Натисніть Ctrl+H.
2. У полі пошуку введіть вихідний текст, у полі заміни — новий.
3. Натисніть «Замінити», щоб змінити один збіг; перевірте результат. «Замінити все» використовуйте, коли впевнені, що потрібні всі входження.

### 2.4. Скасувати останню зміну
1. Після помилкової дії натисніть Ctrl+Z або оберіть «Редагування → Скасувати».
2. Перевірте відновлений текст, перш ніж зберігати документ.
3. За потреби повторіть дію скасування, якщо версія програми підтримує кілька кроків.

### 2.5. Увімкнути перенесення рядків
1. Знайдіть «Перенесення рядків» у меню «Формат» або «Перегляд», залежно від версії.
2. Увімкніть пункт: довгий рядок відображатиметься в межах ширини вікна.
3. Щоб повернути горизонтальне прокручування, вимкніть цей пункт. Перенесення відображення не вставляє символів нового рядка у файл.

Довідка виробника: [Help in Notepad](https://support.microsoft.com/en-us/windows/apps/help-in-notepad).
