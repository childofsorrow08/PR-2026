1) Що таке REST Client?

- Це інструмент для надсилання HTTP-запитів і перегляду відповідей. У VS Code можна використовувати розширення REST Client.

2) Як можна перевірити роботу API без браузера?

- Через REST Client, curl або Postman.

3) Для чого використовуються файли .rest?

- Для збереження запитів, які можна повторно виконувати. Розширення REST Client також підтримує .http.

4) Яким чином формуються HTTP-запити?

- Вказується метод, адреса, заголовки та за потреби тіло запиту.

5) Як розуміти статус відповіді сервера?

- 2xx означає успіх, 3xx перенаправлення, 4xx помилку запиту клієнта, 5xx помилку сервера.

6) Що означає коректна відповідь API?

- Це відповідь з очікуваним статусом, форматом і правильними даними для конкретного запиту.

7) Як перевірити, що сервер повертає дані у форматі JSON?

- Перевірити Content-Type application/json і переконатися, що тіло розбирається як JSON.

8) Чому важливо перевіряти маршрут запиту?

- Неправильна адреса може викликати інший обробник або повернути 404.

9) Як можна виявити помилки в API під час тестування?

- Перевіряти правильні й неправильні дані та порівнювати статус і відповідь з очікуваними.

10) Які основні результати повинен показувати успішний тест запиту?

- Очікуваний статус і правильне тіло відповіді, а для зміни даних ще й правильний стан після запиту.
