1) Що таке REST API?

- Це інтерфейс взаємодії з ресурсами за принципами REST, зазвичай через HTTP.

2) Які основні HTTP-методи використовуються в REST?

- GET для читання, POST для створення, PUT для заміни або оновлення, PATCH для часткових змін та DELETE для видалення.

3) Що таке ендпойнт?

- Це поєднання адреси та HTTP-методу, для якого сервер має обробник.

4) Чому для обміну даними у веб-API використовується JSON?

- JSON легко читати й обробляти, він підтримується різними мовами та підходить для передачі об’єктів і масивів.

5) Що таке Minimal API?

- Це спосіб створення HTTP API в ASP.NET Core через короткі обробники маршрутів без окремих контролерів.

6) Які основні переваги використання Minimal API?

- Мало початкового коду, просте налаштування маршрутів і зручність для невеликих API.

7) Яка роль маршрутизації в API?

- Маршрутизація вибирає обробник за адресою та методом запиту.

8) Як у проєкті організовано взаємодію між сервером та клієнтом?

- Клієнт надсилає HTTP-запит, сервер обробляє його й повертає відповідь. У ПР-36 GET / повертає текст.

9) Яке призначення папок проєкту?

- У цій роботі основний код у Program.cs, .csproj містить налаштування проєкту, bin містить результат складання, а obj проміжні файли.

10) Які поняття необхідно знати перед створенням власного ендпойнта?

- HTTP-методи, маршрути, параметри запиту, статуси відповіді та формат даних.
