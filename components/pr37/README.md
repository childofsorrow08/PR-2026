1) Що таке ендпойнт у REST API?

- Це маршрут і HTTP-метод, за якими доступна певна операція з ресурсом.

2) Для чого використовується метод GET?

- Для отримання даних із сервера.

3) Які дані можуть повертатися з API?

- Об’єкти, масиви, текст, числа, файли або відповідь без тіла. У цій роботі записи повертаються як JSON.

4) Що означає формат JSON?

- JavaScript Object Notation, текстовий формат для передачі структурованих даних.

5) Як зберігаються дані в пам’яті під час виконання програми?

- У списку об’єктів в оперативній пам’яті. Після перезапуску програми вони втрачаються.

6) Яка роль маршруту у URL-адресі запиту?

- Він визначає ресурс, до якого звертається клієнт, наприклад /postings.

7) Як визначити ендпойнт для отримання списку елементів?

- Додати обробник через `app.MapGet("/postings", ...)`, який повертає список.

8) Які компоненти потрібні для створення простого API?

- Вебсервер, маршрути, обробники запитів і джерело даних.

9) Чому важливо повертати дані у структурованому форматі?

- Щоб клієнт міг однозначно прочитати поля й використати результат.

10) Як перевірити, що ендпойнт працює коректно?

- Надіслати запит і перевірити статус, заголовки та дані у відповіді.
