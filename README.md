<h1 align="center">
    Практичні роботи з ООП, Компонентів та веб програмування за 4 курс РКЕПФК 2026 року
</h1>

В цьому репозиторії зроблені усі (або принаймні більшість) практичних які мені треба було зробити на 4 курсі. Були пропущені усі практичні для яких потрібна була наявність Windows, тому що встановленого у мене немає, а встановити його поруч з моїм Linux це та ще задача

Пропущеними через Windows були практичні 31-32 та 46 з ООП, а також 42 та 47-48 з компонентів

Треба dotnet sdk 10
